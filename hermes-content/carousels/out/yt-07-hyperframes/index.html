La composición mínima

El contrato empieza con tamaño, duración y una escena identificable.

Sin estos atributos, el motor no sabe qué superficie debe reproducir ni cuánto tiempo existe.

<div id="root"
  data-composition-id="main"
  data-start="0"
  data-width="1920"
  data-height="1080"
  data-duration="5">
  <section data-start="0"
    data-duration="5"
    data-track-index="1">...</section>
</div>

Movimiento determinista

La línea de tiempo queda pausada porque el motor controla cada fotograma.

La regla evita que preview y render produzcan estados distintos según la velocidad de la computadora.

window.__timelines = {};
const id = "main";

const tl = gsap.timeline({ paused: true });
tl.from("#title", {
  y: 48,
  opacity: 0,
  duration: 0.6
}, 0.2);

window.__timelines[id] = tl;

Flujo de trabajo exacto

Construí, auditá y recién después decidí si renderizar.

Cada comando responde una pregunta distinta; saltarse check convierte un fallo visual en un archivo final.

terminal
$ npx hyperframes init mi-video
$ cd mi-video
$ npx hyperframes lint
$ npx hyperframes check --snapshots
$ npx hyperframes preview
$ npx hyperframes render --quality high --output out.mp4

Deck o video

Una presentación navegable usa present; un video lineal usa render.

Un deck tiene diapositivas discretas, notas y navegación. Renderizar su primera composición puede truncar todo el resto.

PRESENTACIÓN npx hyperframes present .Flechas + notasNo genera MP4
VIDEO npx hyperframes renderTimeline linealGenera MP4/WebM
