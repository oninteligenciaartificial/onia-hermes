# Agentes que trabajan de noche: de 443 avisos a un parte por día

Deck navegable de 11 láminas para grabar una clase de YouTube.

## Promesa

Al terminar, la persona podrá convertir los avisos de sus automatizaciones en tareas, armar un parte diario y vigías que avisan solo cuando algo cambia.

## Abrir

Desde esta carpeta:

```powershell
npx hyperframes present .
```

También se puede abrir `index.html` directamente. Flechas cambian de lámina y `N`
muestra u oculta las notas.

## Orden de grabación

1. Grabar A-roll siguiendo las notas del deck.
2. Grabar las pantallas indicadas en `GUION.md` con datos ficticios.
3. Revisar que no aparezcan credenciales, clientes ni notificaciones.
4. Hacer un primer corte antes de añadir B-roll o animaciones.

## CTA

Los tres pedidos, listos para copiar y pegar (drop D13). Recurso en la comunidad de WhatsApp; el link está en la web.
