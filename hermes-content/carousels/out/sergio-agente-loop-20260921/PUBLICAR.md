## Caption

No todo problema de IA necesita un agente. Elegí la arquitectura por la forma del trabajo:

IF + Google Sheets + Telegram cuando las reglas son fijas.
AI Agent + OpenAI Chat Model cuando hay que leer lenguaje y clasificar.
Schedule Trigger + HTTP Request + IF + Wait cuando hay que revisar un estado hasta que termina.

El criterio no es usar el modelo más nuevo. Es saber cuándo termina el proceso y quién confirma la excepción. Comentá ARQUITECTURA con el proceso que querés ordenar.
