# Claude Code en un servidor, sin API key y con barandas

Deck navegable de 8 láminas para grabar una clase de YouTube.

## Promesa

Al terminar, la persona podrá armar un loop de Claude Code en un servidor con candado, carpeta verificada y aviso, y evitar las cinco trampas.

## Abrir

Desde esta carpeta:

```powershell
npx hyperframes present .
```

También se puede abrir `index.html` directamente. Flechas cambian de lámina y `N`
muestra u oculta las notas.

## Orden de grabación

1. Grabar A-roll siguiendo las notas del deck.
2. Grabar las pantallas indicadas en `GUION.md` con datos ficticios.
3. Revisar que no aparezcan credenciales, clientes ni notificaciones.
4. Hacer un primer corte antes de añadir B-roll o animaciones.

Esqueleto del corredor (drop 8). Recurso en la comunidad de WhatsApp; el link está en la web. Nunca mostrar la terminal del servidor, .env ni credenciales; no decir cuántos loops hay activos.
