# Opus 5.5 o Sonnet 5.5: cuál usar y cómo cambiarlo en Claude Code

Deck navegable de 11 láminas para grabar una clase de YouTube.

## Promesa

Al terminar, la persona sabrá dónde se separan Opus 5.5 y Sonnet 5.5, cómo cambiar modelo y esfuerzo en Claude Code y cómo decidir con una tarea propia.

## Abrir

Desde esta carpeta:

```powershell
npx hyperframes present .
```

También se puede abrir `index.html` directamente. Flechas cambian de lámina y `N`
muestra u oculta las notas.

## Orden de grabación

1. Grabar A-roll siguiendo las notas del deck.
2. Grabar las pantallas indicadas en `GUION.md` con datos ficticios.
3. Revisar que no aparezcan credenciales, clientes ni notificaciones.
4. Hacer un primer corte antes de añadir B-roll o animaciones.

## CTA

El ejercicio de las tres propuestas, con el prompt completo. Recurso en la comunidad de WhatsApp; el link está en la web. La guía para instalar Claude Code está en la web `/claude-code`.
