Salida obligatoria

Structured Output Parser convierte texto libre en datos verificables.

El siguiente nodo no debería adivinar si el modelo escribió una lista, una frase o un JSON incompleto.

{
  "type": "object",
  "properties": {
    "categoria": { "enum": ["web", "automatizacion", "otro"] },
    "urgencia": { "enum": ["baja", "normal", "alta"] },
    "requiere_humano": { "type": "boolean" }
  },
  "required": ["categoria", "urgencia", "requiere_humano"],
  "additionalProperties": false
}

Reglas del Switch
