Frenos obligatorios

Todo loop necesita éxito, máximo de pasos, timeout, presupuesto y salida humana.

Las escrituras además necesitan permisos claros y confirmación; sin límites, el sistema repite costo y error.

done = status === "paid"
maxAttempts = 3
wait = 10 minutes
timeout = 35 minutes
writeRequiresApproval = true

if attempts >= 3:
  notify_human()

Contrato de una tool

Una herramienta bien nombrada reduce decisiones ambiguas del agente.

Separá leer de escribir y declarale al modelo input, output y efecto secundario.

{
  "name": "get_lead_by_id",
  "description": "Lee un lead por ID exacto; no modifica datos.",
  "inputSchema": {
    "type": "object",
    "properties": { "lead_id": { "type": "string" } },
    "required": ["lead_id"],
    "additionalProperties": false
  },
  "annotations": { "readOnlyHint": true }
}
