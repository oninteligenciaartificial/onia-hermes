## Caption

MCP no es un modelo. Es un protocolo para que un cliente como Claude Code use herramientas de un servidor con un contrato claro.

Comando de ejemplo para Notion:
`claude mcp add --transport http notion https://mcp.notion.com/mcp`

Después verificás con `claude mcp list` y autenticás desde `/mcp`. Antes de usarlo, definí herramienta, input, output y permisos. Un agente puede leer un lead; no debería borrar registros ni enviar mensajes solo porque tiene acceso.

Comentá MCP si querés que el próximo video muestre el contrato completo de una herramienta.
