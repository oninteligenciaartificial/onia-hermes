# Un CLAUDE.md donde cada regla trae su historia

Deck navegable de 9 láminas para grabar una clase de YouTube.

## Promesa

Al terminar, la persona podrá escribir un CLAUDE.md ordenado por cuándo se necesita, con reglas que traen su historia, y comprobar que se leen.

## Abrir

Desde esta carpeta:

```powershell
npx hyperframes present .
```

También se puede abrir `index.html` directamente. Flechas cambian de lámina y `N`
muestra u oculta las notas.

## Orden de grabación

1. Grabar A-roll siguiendo las notas del deck.
2. Grabar las pantallas indicadas en `GUION.md` con datos ficticios.
3. Revisar que no aparezcan credenciales, clientes ni notificaciones.
4. Hacer un primer corte antes de añadir B-roll o animaciones.

## CTA

Plantilla de regla con historia (drop 4). Recurso en la comunidad de WhatsApp; el link está en la web.
