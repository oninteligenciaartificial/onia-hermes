# Viral Video Playbook

This playbook tells Hermes how to plan short-form videos that have a real
chance of being watched, saved and shared.

## Viral Is Not Random

Hermes should optimize for:

- immediate clarity
- curiosity gap
- emotional truth
- visible transformation
- simple CTA

Do not optimize for generic "cinematic" output unless the content idea needs it.

## The 5-Part Viral Stack

### 1. Pattern Interrupt

Open with something that breaks scrolling:

- a strong claim
- a surprising visual
- a before/after
- a screen with an unexpected result
- a founder confession
- a "mistake I made" angle

### 2. Pain Recognition

Make the viewer feel:

```text
This is my problem.
```

### 3. Mechanism

Show the thing that makes the result believable:

- workflow
- automation
- product
- dashboard
- process
- checklist
- real screen

### 4. Proof Or Specificity

Add one specific proof element:

- a real screen
- a specific metric if verified
- a before/after process
- a real objection
- a real constraint
- a customer scenario

### 5. CTA

Use one CTA only:

- "Escribeme sistema"
- "Pide auditoria"
- "Comenta lead"
- "Guarda esto"
- "Mira el flujo completo"

## Formats

### Talking Head

Best for Sergio and expert trust.

Use:

- direct camera
- one idea
- subtitles
- one screen insert

### UGC Ad

Best for client offers and products.

Use:

- human narrator
- natural language
- product/service in context
- objection handling

### Workflow Demo

Best for Onia.

Use:

- screen recording
- before/after
- clear labels
- no excessive animation

### Cinematic Concept

Best for top-of-funnel awareness.

Use:

- metaphor
- product/category mood
- strong visual hook

### Story Sequence

Best for Sergio daily presence.

Use:

- 3-5 frames
- informal updates
- one poll/question/CTA

## Retention Checklist

Before generation, Hermes should check:

- Is the first 2 seconds clear?
- Can the viewer understand without audio?
- Is there one main idea?
- Is the CTA obvious?
- Is the visual different every 3-5 seconds?
- Is any claim unverifiable?

## Default Script Length

- 15s: 35-45 spoken words.
- 30s: 75-90 spoken words.
- 45s: 110-130 spoken words.

If a script is longer, create a carousel or multi-part sequence instead.
