# Historial

Fotos de un dia. **Nada de aca es fuente de verdad.**

Un documento con fecha en el nombre (`_20260726`) describe como estaban las
cosas ese dia. Sirve para reconstruir por que se decidio algo, no para saber
que es cierto hoy.

Si buscas el estado actual de un tema, esta en `hermes-content/docs/` sin
fecha en el nombre. Si lo que encontraste aca contradice a un doc sin fecha,
**gana el doc sin fecha**.

Se movieron 102 documentos aca el 2026-08-15. Quedaron afuera 20 que estan
referenciados desde `CLAUDE.md` o desde las skills: esos se usan como fuente
de verdad a pesar de tener fecha, que es justo la contradiccion que este
ordenamiento busca eliminar. Hay que convertirlos en docs sin fecha o dejar
de citarlos.
