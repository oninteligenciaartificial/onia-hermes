## Hallazgos de las 3 referencias

### Referencia 001

Mejor para: demostraciones sorpresa de herramientas IA.

Patron:

```text
curiosidad visual -> reaccion de creador -> interfaz/archivo -> tool reveal
-> workflow proof -> segundo ejemplo
```

Usar cuando queremos que Onia parezca magico pero practico.

No copiar:

- cara;
- mascota/escena exacta;
- texto exacto;
- watermark;
- secuencia exacta.

### Referencia 002

Mejor para: educacion de IA y autoridad.

Patron:

```text
talking head -> ejemplo -> grafico principiante/experto -> prueba visual
-> interfaz/codigo -> tablero de herramienta
```

Usar cuando Sergio quiere ensenar una skill o proceso.

### Referencia 003

Mejor para: posicionar Higgsfield/Supercomputer como workflow premium.

Patron:

```text
future shock -> tool reveal -> paso visual -> character lock -> storyboard
-> frames to film
```

Esta es la referencia mas util para vender el nivel nuevo de Onia.

## Workflow recomendado

### Workflow 1: referencia a video Onia

Entrada:

- video de referencia;
- objetivo Onia;
- plataforma;
- CTA.

Proceso:

1. Extraer hook, ritmo, escenas, proof y CTA.
2. Definir que NO se puede copiar.
3. Crear angle original Onia.
4. Crear guion de 6 beats.
5. Crear prompt Higgsfield.
6. Crear caption y variantes.
7. Crear job en Video Lab.
8. Generar solo con aprobacion.

Resultado:

- brief listo para aprobar.

### Workflow 2: Supercomputer como estudio creativo

Usar cuando:

- necesitamos 10+ variantes;
- queremos clips de video largo;
- queremos investigar competencia creativa;
- queremos campana completa;
- queremos crear skills creativas.

Proceso:

1. Supercomputer crea hooks, angulos, shot lists o variantes.
2. Hermes rankea y filtra.
3. Hermes convierte los mejores en Video Lab jobs.
4. Higgsfield genera solo tras aprobacion.

No usar Supercomputer para publicar, secretos, finanzas o aprobaciones.

## Hooks listos

2. Alguien me explica como este video salio de una sola referencia?

## Guion recomendado para el primer video

```text
0-2s:
En 2026, vender videos no sera editar: sera controlar personajes, escenas y pruebas visuales.

2-6s:
La mayoria genera videos bonitos, pero no sabe convertirlos en una oferta.

6-12s:
Yo lo estoy armando asi: referencia, patron, guion, prompt, aprobacion y render.

12-20s:
Hermes analiza el ritmo del creador, pero no copia su cara, su voz ni sus frases.

20-28s:
Luego Higgsfield crea la escena: personaje, escenografia, camara, storyboard y CTA.

28-35s:
Si quieres, dime tu rubro y te preparo una idea de video lista para producir.
```
