# Onia Consulting Services 2026

## Decision

Onia debe vender tambien consultoria e implementaciones. No solo cobramos por
"hacer una web", "hacer videos" o "instalar un sistema"; cobramos por diagnostico,
criterio, configuracion, proceso, capacitacion y acompanamiento.

La marca correcta es:

- Onia: empresa, contrato, entrega, sistema, metodologia y continuidad.
- Sergio: cara consultiva, operador principal, autoridad y confianza.

Sergio no debe reemplazar a Onia. Sergio abre la relacion, explica el criterio y
puede liderar las consultorias premium. Onia cobra y documenta el servicio.

## Por que vender consultoria

Los gastos fijos de Onia obligan a proteger margen. Los servicios consultivos
permiten cobrar por pensamiento, instalacion y mejora operativa, no solo por
produccion.

Esto agrega margen porque:

- requiere menos creditos de video que producir piezas sin direccion;
- convierte herramientas existentes en soluciones instaladas;
- crea tickets iniciales altos antes del retainer;
- aumenta la probabilidad de vender DentalGest, Gesti-OS, web o Higgsfield;
- permite cobrar acompanamiento mensual sin prometer ventas garantizadas.

## Lineas de servicio

### 1. Auditoria Express

| Campo | Detalle |
|---|---|
| Precio | Bs. 250-450 |
| Duracion | 30-45 minutos |
| Ideal para | Negocio que quiere saber que esta perdiendo o que automatizar primero |
| Entrega | Diagnostico corto, 3 mejoras prioritarias y recomendacion de paquete |
| Regla | Puede descontarse de una implementacion si compra en 7 dias |

Usar cuando el prospecto todavia no confia o no entiende el valor.

### 2. Diagnostico + Roadmap

| Campo | Detalle |
|---|---|
| Precio | Bs. 790-1,200 |
| Duracion | 1 sesion + documento de ruta |
| Ideal para | Clinicas, pymes, profesionales y equipos con procesos desordenados |
| Entrega | Mapa de problemas, flujo recomendado, herramientas, costos y siguientes pasos |
| Regla | No incluye implementacion tecnica |

Usar cuando el cliente necesita direccion antes de comprar software o contenido.

### 3. Instalacion Starter

| Campo | Detalle |
|---|---|
| Precio | Bs. 1,900 |
| Duracion | 3-5 dias habiles |
| Ideal para | Un flujo concreto: leads, CRM, web form, Notion, n8n o contenido |
| Entrega | Flujo instalado, prueba, mini SOP y llamada de entrega |
| Regla | Herramientas de terceros, dominios, hosting, pauta y APIs se cobran aparte |

Ejemplos:

- formulario web a CRM;
- Notion/CRM simple de leads;
- n8n de aprobaciones internas;
- tablero de seguimiento comercial;
- flujo de aprobacion interna con registro y responsable.

### 4. Implementacion Operativa

| Campo | Detalle |
|---|---|
| Precio | Bs. 3,900-6,500 |
| Duracion | 1-2 semanas |
| Ideal para | Empresas que necesitan ordenar operacion completa |
| Entrega | Diagnostico, instalacion, automatizaciones base, capacitacion y SOPs |
| Regla | Requiere 50% de anticipo |

Usar para Gesti-OS, DentalGest con equipo, CRM, reportes o procesos con varios
responsables.

### 5. Sprint n8n y Seguimiento

| Campo | Detalle |
|---|---|
| Precio | Bs. 1,900-3,900 |
| Duracion | 1-2 semanas |
| Ideal para | Negocios con leads, tareas o aprobaciones que se pierden |
| Entrega | Mapa del flujo, automatizacion n8n, tablero simple, alertas y capacitacion |
| Regla | No incluye WhatsApp automatico, APIs pagadas ni soporte continuo |

Componentes posibles:

- captura de leads desde formulario, planilla, email o carga manual;
- registro en Notion, Google Sheets, CRM o tablero interno;
- aviso por Telegram o email;
- tarea con responsable y fecha;
- flujo de aprobacion simple cuando corresponde.

### 6. Acompanamiento Consultivo

| Campo | Detalle |
|---|---|
| Precio | Bs. 1,200-2,900/mes |
| Duracion | Mensual |
| Ideal para | Cliente que ya tiene sistema instalado y quiere mejora continua |
| Entrega | 2 reuniones, revision de metricas, mejoras pequenas y priorizacion |
| Regla | No reemplaza desarrollo grande ni produccion ilimitada |

### 7. Transformacion Onia

| Campo | Detalle |
|---|---|
| Precio | Desde Bs. 9,500 |
| Duracion | Cotizado |
| Ideal para | Sistemas a medida, portales, integraciones, dashboards o multi-area |
| Entrega | Discovery, plan, implementacion por fases y soporte |
| Regla | Cotizar margen antes de prometer comision |

## Que se puede instalar

- DentalGest o Gesti-OS.
- CRM simple para leads.
- Notion operativo.
- n8n con aprobaciones.
- formularios web y captura de contactos.
- dashboards de ventas u operacion.
- Google Workspace operativo: carpetas, permisos, formularios y docs.
- flujo de seguimiento: lead, responsable, tarea, aprobacion y reporte.
- conectores internos a Telegram, email, Google Sheets, Notion o CRM cuando las
  credenciales lo permitan.

| Servicio | Comision sugerida |
|---|---:|
| Auditoria Express | 10% del pago neto |
| Diagnostico + Roadmap | 10% del pago neto |
| Instalacion Starter | 10% del pago neto |
| Implementacion Operativa | 8-10% del pago neto |

## Como venderlo

Mensaje base:

```text
Hola, soy Sergio de ONIA. No quiero venderte una herramienta suelta. Podemos
hacer una auditoria corta de tu proceso y decirte que conviene instalar primero:
CRM, seguimiento, web, automatizacion, contenido o dashboard.

La idea es que te lleves un sistema funcionando, no solo una recomendacion.
```

Mensaje para vendedores:

```text
ONIA puede revisar tu proceso y dejarte instalado un flujo concreto: leads,
seguimiento, contenido, reportes o automatizaciones. Si quieres, primero hacemos
una auditoria express y te decimos que tiene mas retorno ordenar.
```

CTA recomendado:

```text
Te agendo una auditoria corta con Sergio/ONIA y vemos que flujo conviene instalar
primero.
```

## Sergio vs Onia

Usar Sergio cuando:

- el cliente necesita confianza;
- el ticket es alto;
- hay consultoria estrategica;
- se graba contenido de autoridad;
- se explica el criterio de negocio.

Usar Onia cuando:

- se cotiza;
- se firma;
- se cobra;
- se documenta;
- se entrega;
- se da soporte.

Formula:

```text
Sergio es la cara. ONIA es la empresa y el sistema.
```

## Reglas

- No prometer ventas garantizadas.
- No prometer automatizaciones con WhatsApp hasta verificacion Meta.
- No incluir herramientas de terceros en el precio salvo que este escrito.
- No publicar ni contactar clientes sin aprobacion explicita.
- No hacer implementaciones sin anticipo.
- No entregar estrategia completa gratis si el prospecto no pago auditoria.
- Todo diagnostico pago debe terminar con una recomendacion accionable.
