Sistema operativo para crear una modelo IA profesional, original y reutilizable

sin aprobacion explicita.

## 1. Resumen ejecutivo

La oportunidad comercial mas fuerte no es crear una "influencer IA" generica.
La oportunidad es crear una modelo IA de producto, consistente y modular, que
pueda aparecer en fotos, videos cortos, demos, unboxings, catalogos y piezas de
conversion para marcas pequenas y ecommerce.

Veredicto v1:

- Ruta ganadora: Ruta 2, modelo natural tipo UGC.
- Mejor uso comercial inmediato: TikTok Ads, Meta Reels Ads, ecommerce local,
  tiendas de skincare, ropa, accesorios y productos virales.
- Por que gana: produce piezas mas creibles, baratas y repetibles; encaja con
  el formato que compra el cliente local; reduce rechazo por "modelo IA"; y se
  puede empaquetar como servicio mensual de creativos.
- Ruta secundaria de mayor margen: Ruta 1, premium elegante, para skincare,
  perfumes, moda y marcas con estetica cuidada.
- Ruta exploratoria: Ruta 3, lifestyle moderna, para accesorios, ropa y
  productos virales cuando se necesita volumen social.

Principio central:

```text
Primero consistencia de identidad, despues estilos. Primero producto claro,
despues belleza. Primero conversion, despues fantasia visual.
```

## 4. Modelo IA v1: identidad base

Nombre comercial: Mara Vale

Concepto:

Mara Vale es una modelo IA original para ecommerce y anuncios sociales. No es
celebridad, no copia creadoras reales y no simula ser cliente real. Su funcion es
modelar productos y presentar demos visuales con una energia humana, limpia y
comercial.

Ficha:

| Tono de comunicacion | Claro, natural, sin hype exagerado |
| Estetica visual | Realismo comercial, piel natural, luz limpia |
| Tipo de cuerpo | Proporcionado, saludable, no extremo |

- Debe parecer una persona fotografiada, no un render.

## 5. Tres rutas visuales de la modelo

## 7. Sistema de consistencia visual

### Flujo recomendado

```text
Identidad escrita
-> 12 stills base sin producto
-> seleccion humana de 3 mejores
-> banco de referencias aprobado
-> Soul ID / character reference
-> imagenes ecommerce con producto
-> video corto con movimiento minimo
-> QA de identidad
-> registro en biblioteca ONIA
```

### Metodo primario

1. Generar 12 retratos base de Mara Vale sin productos.
2. Elegir 3 imagenes maestras:
   - rostro frontal;
   - rostro 3/4;
   - medio cuerpo.
3. Entrenar o fijar identidad con Higgsfield Soul ID si esta disponible por CLI.
4. Usar Soul 2.0/Nano Banana Pro para imagenes estaticas.
5. Usar Marketing Studio Video, Seedance 2.0, Kling 3.0 o Veo 3.1 para video,
   siempre desde still aprobado.
6. Animar con movimiento minimo antes de hacer talking head o gestos complejos.

### Por que este metodo

La experiencia local con el avatar de Sergio mostro que primero debe aprobarse
un still maestro. Los videos con movimiento amplio aumentan riesgo de drift en
ojos, boca, cuello, manos y edad. Higgsfield Soul ID esta orientado a bloquear
identidad y Soul 2.0 a producir presets realistas y consistentes.

### Variables bloqueadas

- cara;
- edad aparente;
- tono de piel;
- ojos;
- nariz;
- labios;
- forma de rostro;
- cabello;
- proporciones corporales;
- no sexualizacion;
- no celebridad.

### Variables flexibles

- outfit;
- fondo;
- iluminacion;
- producto;
- formato;
- camara;
- energia premium/UGC/lifestyle.

### Score QA por pieza

| Criterio | Peso |
|---|---:|
| Identidad coincide con banco | 30 |
| Producto se entiende | 20 |
| Realismo humano | 15 |
| Mano/producto sin errores | 10 |
| Cumple ruta visual | 10 |
| Claims seguros | 10 |
| Formato correcto | 5 |

Publicar o entregar solo si supera 85/100.

## 10. Sistema de produccion

```text
Producto recibido
-> analisis del producto
-> buyer persona
-> angulo de venta
-> claims permitidos y prohibidos
-> ruta visual: UGC, premium o lifestyle
-> guion / shot list
-> imagen de Mara con producto
-> video corto o animacion
-> voz IA si aplica
-> subtitulos
-> edicion
-> formatos: 9:16, 1:1, 4:5, 16:9
-> aprobacion
-> publicacion o entrega
-> metricas
-> nuevas variantes
```

Cadencia recomendada para cliente:

- Dia 1: brief, producto, claims, referencias.
- Dia 2: 3 conceptos y 3 stills.
- Dia 3: cliente elige ruta.
- Dia 4: producir piezas.
- Dia 5: QA, edicion y entrega.

## 16. Riesgos y reglas legales

Riesgos:

- parecido involuntario con persona real;
- uso de marca/producto sin permiso;
- claims falsos;
- before/after enganoso;
- publicidad de salud, belleza, suplementos o finanzas;
- rechazo por contenido AI si no se declara cuando corresponde;
- manos/productos deformados;
- cliente pensando que es testimonial real.

Reglas seguras:

- Mara Vale es 100% ficticia.
- No copiar celebridades, modelos, influencers, gestos, voz ni branding.
- No afirmar que Mara compro, probo o recomienda como cliente real.
- No usar logos sin asset y permiso.
- No hacer promesas de resultados.
- No crear antes/despues salvo que haya prueba real y aprobacion.
- Marcar como AI-generated o synthetic cuando la plataforma o el cliente lo
  requiera.
- Guardar prompts, assets, aprobaciones y versiones.
