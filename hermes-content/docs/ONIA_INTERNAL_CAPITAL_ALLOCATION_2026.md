## Home lab

El home lab sirve para reducir costos y acelerar pruebas, no para reemplazar
produccion critica.

Usos correctos:

- ambiente de desarrollo de Supabase/n8n/Open WebUI;
- almacenamiento local y backups de media/proyectos;
- pruebas de modelos locales para borradores, clasificacion, embeddings y RAG;
- procesamiento batch de assets internos;
- mirror de datos no sensibles para pruebas;
- laboratorio de ComfyUI/Wan si el hardware lo soporta.

Usos incorrectos:

- alojar servicios publicos de clientes desde internet de casa;
- guardar secretos sin cifrado;
- depender del home lab para cobros, demos o uptime comercial;
- exponer puertos sin VPN/tunel seguro;
- intentar reemplazar Higgsfield o cloud video antes de validar calidad/costo.

Reducir costos:

- usar modelos locales para borradores, resumen, clasificacion y research
  interno;
- usar almacenamiento local para material bruto en vez de subir todo a cloud;
- mantener staging local para no pagar otro VPS de pruebas;
- usar backups locales cifrados para no depender solo del servidor.

Inversion inicial recomendada:

- UPS/regulador para laptop/router/discos;
- SSD externo o disco de backup;
- RAM/SSD solo si el equipo actual lo soporta;
- Tailscale/Cloudflare Tunnel para acceso privado;
- no comprar servidor grande hasta medir uso real.

## Matriz ejecutiva de prioridad

Orden para decidir cualquier servicio o inversion:

```text
1. Riesgo
2. Inversion requerida
3. Rentabilidad probable
4. Facilidad de ejecutar esta semana
```

Si una idea es rentable pero tiene alto riesgo o requiere mucha caja, no entra
primero. Si una idea es facil pero no genera ventas, solo entra si mejora Onia,
Nuvia o el sistema de forma medible.

Escala:

- Riesgo: bajo, medio, alto.
- Inversion: baja, media, alta.
- Rentabilidad: baja, media, alta.
- Facilidad: facil, media, dificil.

## Reglas por tipo de inversion

### Onia primero

Se mantiene antes que todo:

- Codex;
- Claude si sigue aportando mas que duplicando;
- Higgsfield mientras produzca demos, anuncios o piezas vendibles;
- VPS, Supabase, n8n, Uptime Kuma, LiteLLM, Open WebUI y Stirling PDF;
- Google Workspace/Drive/fotos si organiza operacion y media.

### Nuvia

Invertir solo si:

- hay margen bruto estimado superior a 40%;
- existe costo completo del lote;
- hay plan de contenido y venta;
- se registra propietario del capital;
- no se usa pauta si no hay stock, margen y seguimiento.

### Onia Media Studio

Invertir solo si:

- el equipo permite grabar clientes reales;
- hay paquetes cerrados;
- se cobra anticipo;
- pauta y costos externos van aparte;
- se registra uso premium de Higgsfield/voz/musica/render.

### YouTube/ONIA Media channels

Tratar como activo de largo plazo:

- no pagar comisiones por monetizacion inexistente;
- no consumir mas de 2-3 bloques semanales hasta que haya traccion;
- usar contenido reciclable para Onia, ventas y autoridad;
- separar canal, tema, responsable, costo y propiedad desde el dia 1.

### Home lab

Usarlo para reducir costos y riesgo:

- backups locales cifrados;
- staging/dev;
- pruebas IA locales pequenas;
- storage de material bruto;
- no alojar servicios publicos de clientes desde casa.

### Hardware grande

Compra permitida solo si:

1. Onia tiene 2 meses de operacion cubiertos;
2. hay ingresos nuevos cobrados o contrato firmado;
3. el equipo actual bloquea entrega real;
4. la compra tiene retorno medible en tiempo, calidad o costo.

## Criterios de exito en 30 dias

La inversion fue correcta si produjo:

- herramientas pagadas sin atrasos;
- deuda bajo control;
- Onia Center con capital interno;
- 3 demos audiovisuales vendibles;
- 1 paquete Onia Media Studio listo para cotizar;
- Nuvia con margen medido;
- 1 prueba Meta Ads con seguimiento real;
- home lab con backup o ahorro real;
- minimo 3 reuniones comerciales nuevas;
- minimo 1 propuesta enviada;
- ninguna compra grande sin cliente o retorno claro.

Si no produce reuniones, propuestas o mejoras de entrega, se congela la bolsa de
crecimiento y se vuelve a caja, ventas y seguimiento.
