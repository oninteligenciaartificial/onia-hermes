# Contención POSIX del canario CLI — 13 oct 2026

**META:** impedir que un descendiente del CLI de prueba sobreviva a cancelación, timeout o salida temprana de la raíz en Linux. **PRUEBA DE HECHO:** procesos Python sintéticos, con hijo que hereda stdout y proceso testigo ajeno; ninguna llamada a Codex real. **PARADA:** si la creación del grupo o la unión del CLI falla, la llamada del modelo no empieza.

Base preservada: commit `5d1dc8720856c6fd78a2cd3dacdb5d2acb310638` de la rama Windows. QA reprodujo que la ruta POSIX anterior omitía `killpg` cuando `process.poll()` ya indicaba raíz terminada; un hijo propio con stdout heredado seguía vivo. Los tests anteriores sólo verificaban la muerte del hijo en Windows.

`posix_group.py` crea un proceso Python pequeño, sin red, como líder de un grupo POSIX nuevo en la misma sesión. Se mantiene vivo y sin cosechar mientras corre el CLI; el CLI se lanza dentro de ese grupo. En el cierre se envía `SIGKILL` al grupo cuyo líder propio aún reserva el ID, aun si el CLI raíz ya terminó. Después se esperan los handles del CLI y del líder. Si el líder no arranca o el CLI no puede unirse, se falla antes de inferencia. No se enumeran PIDs ajenos ni se mata un PID reciclado. `codex_cli_experimental.py` usa esta ruta sólo en POSIX; Windows conserva Job Object.

Pruebas focales: timeout, evento de herramienta y raíz que sale con hijo heredando stdout terminan a ese hijo; éxito también cierra un descendiente propio que no hereda el pipe. Un proceso testigo ajeno termina normalmente. Windows local: 12/12 PASS. QA Linux independiente: 11 PASS, 1 test exclusivo Windows omitido, Python 3.11.16, y caso adicional de fallo antes de ejecutar CLI con keeper recolectado PASS; artefacto `E:/onia-wt/qa-linux-fixed-results-20261013.json` SHA-256 `B27D1F09D653F50404D22A8962594CA3141C6FE4BE87CBB305069D135AEC52BD`. El grupo cubre procesos que permanecen en él; un descendiente que cree otra sesión/grupo queda fuera de esta contención, y la CLI sigue sin prohibición técnica global de herramientas/red. No habilita `dispatch_external`, VPS, producción ni nueva inferencia.
