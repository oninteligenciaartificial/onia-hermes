# H-IA-06 · HyperFrames: cuándo un título por código sí ayuda

Si cada semana querés el mismo título animado con una frase distinta, hacerlo por código puede tener sentido. Si lo que necesitás es elegir una buena toma, un título animado no te resuelve ese problema.

HyperFrames es un proyecto de HeyGen para convertir composiciones con HTML, CSS, archivos de medios y animaciones en videos. La parte interesante es que podés describir un formato y reutilizarlo con cambios. No significa que toda edición deba convertirse en programación.

Para empezar, yo elegiría una pieza mínima. Un fondo, una frase y una entrada sencilla. Nada de construir el video completo en el primer intento. La prueba es que el texto se lea, el movimiento termine y la exportación conserve lo que revisaste.

Supongamos un cartel que dice tres pasos para revisar una fuente. Es un ejemplo de composición, no un render que esté mostrando como si ya existiera. Definís el tamaño, cuánto dura y dónde va la frase. Después decidís qué palabra merece énfasis. Si resaltás todas, el énfasis deja de ordenar.

El repositorio de HyperFrames describe un flujo para crear, previsualizar y renderizar. Renderizar es producir el archivo de video. Previsualizar es revisar la composición antes. Los comandos y requisitos se tienen que mirar en la versión que vas a usar; no copiar una captura vieja como si fuera el manual actual.

El render local es parte del proyecto abierto. Eso no vuelve gratis cualquier servicio, modelo o recurso que uses alrededor. Si le pedís a otra herramienta una imagen paga, ese costo es distinto. Y si aparece música o una foto ajena, sus derechos también se revisan aparte.

¿Qué miraría en el preview? Primero el texto. Que no salga cortado, que tenga contraste y que alcance el tiempo para leerlo. Después el movimiento. Que la entrada ayude a encontrar la frase y que no la haga perseguir por la pantalla.

También miraría el último cuadro. A veces la animación entra muy bien y el cierre queda vacío o dura demasiado poco. Si el objetivo es un cartel legible, el tiempo quieto importa tanto como la entrada.

Después revisaría el archivo exportado completo. Un preview correcto no me permite asumir que la salida quedó idéntica. Hay que mirar tamaño, duración, texto y audio si lo tiene. Y conservar la versión del proyecto que produjo ese archivo, para poder cambiar la frase sin empezar desde cero.

¿Dónde lo usaría? En títulos que se repiten, listas visuales o una comparación con datos que ya comprobaste. ¿Dónde empezaría con otra cosa? En una entrevista donde la decisión principal es qué respuesta conservar. Ahí primero necesitás escuchar y editar el contenido.

La base vertical de este tema sirve para presentar la herramienta. En un horizontal, lo útil es decidir si merece entrar en tu proceso y cómo revisar una pieza mínima. No hace falta prometer que reemplaza toda la edición.

Probá con un cartel sencillo y una razón clara para animarlo. Si mejora la explicación y podés reproducirlo, tenés un formato útil. Si solo agrega movimiento, todavía queda decidir si ese movimiento ayuda a quien mira.
