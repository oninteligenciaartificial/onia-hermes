# IA-1019-1 · Una skill necesita una receta, no un deseo

Una skill es una receta que una IA puede cargar para hacer una tarea. En Claude Code, se escribe en un archivo llamado skill punto eme de.

La documentación explica que puede incluir instrucciones y archivos de apoyo. Claude puede usarla cuando corresponde, o vos podés llamarla por su nombre.

Mi consejo: escribí qué entra, qué tiene que salir y cómo se comprueba. Decir hacelo profesional no le da un criterio claro para revisar el resultado.

Un ejemplo sería una receta para revisar un texto: conservar los datos, señalar afirmaciones sin fuente y separar cambios necesarios de preferencias de estilo. Es un ejemplo de pedido, no una prueba que corrí.

Antes de instalar una receta ajena, leela. Si puede ejecutar comandos o usar otras herramientas, mirá también esos permisos.

La receta organiza el método. Para saber si sirve, todavía necesitás comparar el resultado con lo que pediste.

# IA-1019-2 · Menos preguntas no significa menos permisos

Que una IA deje de preguntarte a cada rato no demuestra que esté trabajando con menos permisos.

Claude Code tiene modos de permisos y reglas para permitir, preguntar o negar herramientas. La documentación explica cómo configurar esos límites. No son todos el mismo modo con un nombre distinto.

Mi consejo es revisar qué tarea querés delegar. Para leer un archivo y resumirlo, el acceso necesario es distinto del que hace falta para editar, ejecutar comandos o publicar.

Una instrucción como no borres nada ayuda a expresar el pedido, pero no reemplaza una restricción real de la herramienta o del entorno.

Antes de dejar trabajo automático, mirá las reglas y el alcance de acceso. Si no entendés una opción, no la actives solo para sacar una ventana molesta.

No te prometo cero errores ni seguridad total. El objetivo es dar el acceso que la tarea necesita y conservar una forma de revisar lo que hizo.

# INF-1019 · Qué quiero guardar y qué descartar

Al cerrar una semana, quiero guardar lo que me permite seguir sin empezar de cero. No todo lo que pasó merece una carpeta nueva.

Quiero conservar los originales, la versión que revisé y una nota de lo que falta. Si hay dos archivos parecidos, me interesa saber cuál es el vigente y por qué.

También quiero separar descartar una idea de borrar una fuente. Una idea puede no servir para esta semana. El material original puede seguir siendo necesario para revisar un corte después.

No te cuento que ya limpié todo ni que mi sistema está perfecto. Es el criterio que quiero usar para cerrar el trabajo.

Mi pregunta final sería sencilla: si retomo esto mañana, ¿puedo encontrar el archivo correcto y entender el siguiente paso?

Si puedo, la nota sirve. Si solo dice avanzamos bastante, todavía me falta dejar algo concreto.
