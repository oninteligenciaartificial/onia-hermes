# IA-1016-1 · Un plugin también necesita examen

Instalar un plugin no demuestra que Claude trabaje mejor. Anthropic tiene una herramienta para comparar eso: claude plugin eval.

La función aparece en su resumen del siete al once de septiembre. Te cuento un hecho documentado, no una noticia que acaba de salir.

La herramienta corre casos con el plugin y también sin él. Después compara los resultados con los criterios que definiste. Puede ayudarte a distinguir mejora real de una respuesta que solo suena distinta.

Mi consejo es escribir primero qué tiene que lograr la tarea. Por ejemplo: conservar un dato, respetar un formato o pasar una prueba. Si cambiás el examen después de ver quién ganó, la comparación pierde sentido.

No te muestro una corrida mía ni un ganador universal. Las pruebas pueden consumir tu uso del modelo. Antes de lanzarlas, revisá versión, alcance y costo. Un plugin se evalúa por lo que hace, no por lo bien que promete.

# IA-1016-2 · La skill que nunca usás también ocupa lugar

Podés tener muchas skills y no saber cuáles usa Claude. Una skill es una receta de instrucciones para el agente.

Claude Code tiene barra skill-doctor para mirar cuánto espacio ocupan las skills y con qué frecuencia se invocan. Anthropic lo incluyó en su resumen del treinta y uno de agosto al cuatro de septiembre.

La documentación actual pide la versión dos punto uno punto doscientos cincuenta y dos o posterior. También aclara que el reporte no cubre todas las categorías de skills y que no está disponible por cualquier conexión.

Mi consejo: usá ese informe para revisar, no para borrar todo lo que aparece sin uso. Puede haber una receta que solo necesitás en una tarea poco frecuente.

Primero preguntá si sigue haciendo falta. Después mirá su costo y cuándo se activa. Tener más recetas no demuestra que las tareas salgan mejor. Hay que mirar cuáles ayudan de verdad.

# INF-1016 · Cómo quiero preparar mi espacio para grabar

Quiero preparar el lugar antes de grabar, para no estar resolviendo la cámara mientras intento explicar una idea.

El plan es dejar el teléfono fijo, mirar si el encuadre sirve y comprobar el audio con una toma breve. No quiero descubrir al terminar que el micrófono estaba rozando la ropa.

También quiero separar las pantallas que necesito. Tener una lista de capturas me parece más útil que abrir ventanas a medida que hablo y mostrar sin querer una notificación.

Si varias piezas usan la misma escena, quiero grabarlas juntas. Pero cada una sigue teniendo su propia idea y su propio cierre.

No te enseño un estudio perfecto ni te digo que ya tengo este hábito resuelto. Es una preparación concreta que quiero hacer.

Antes de sumar luces o comprar algo, prefiero revisar lo básico: se ve, se escucha y se entiende lo que estoy diciendo.
