# SI-08 · Un video escrito con ayuda de Claude

Mirá esto. Claude ayudó a escribirlo. Es una animación hecha con HyperFrames, una herramienta de HeyGen.

En el proyecto hay HTML y animaciones: la escena se escribe como una página web y después se convierte en video. Tenemos un ejemplo existente, no hace falta inventar que apareció de la nada.

El render local es gratis. Eso no significa que cualquier servicio en la nube, música o generación adicional también lo sea.

El flujo básico tiene tres pasos: crear el proyecto, mirar una vista previa y exportarlo.

Puede trabajar con texto, imágenes y video existente. No te voy a decir que no edita grabaciones, porque también tiene herramientas para poner gráficos y subtítulos sobre ellas.

Mi consejo: mirá primero una versión corta. Revisá el texto, el movimiento y que se entienda en el celular. Que el proyecto abra no demuestra que el video final esté bien.

# SI-09 · La IA te da links. Abrí dos.

La IA te da links. ¿Alguna vez abriste uno?

Claude Code tiene barra deep-research, un flujo para investigar a fondo. Puede preparar un informe con citas: enlaces que deberían mostrar de dónde salió cada dato.

Para usarlo necesita búsqueda web. En el plan Pro, los flujos se habilitan en la configuración. Antes de una demo, hay que comprobar tu versión y acceso.

Ahora, mi consejo: abrí dos citas. Buscá la frase o el dato, mirá la fecha y comparalo con el informe.

Si una página no existe o dice otra cosa, no uses ese dato. Pedí una fuente que lo respalde. Si las dos coinciden, comprobaste esos dos puntos; no todo el informe.

Eso vale con cualquier IA que te dé enlaces. Una lista de fuentes no es una revisión terminada. El link es el lugar donde empieza la comprobación, no donde termina.

# INF-1015 · Mi checklist antes de confiar en una IA

Quiero tener una lista corta antes de aceptar el listo de una IA. No una lista enorme que después nadie mira.

Primero, qué tenía que quedar hecho. Si el pedido era vago, no puedo juzgar el resultado con una regla que invento al final.

Segundo, qué puedo abrir y revisar. Un archivo, una captura o una prueba que se pueda repetir. Una explicación muy segura no reemplaza eso.

Tercero, qué quedó pendiente. Me sirve que diga no pude comprobar esto. Me sirve menos que esconda esa parte para que todo parezca cerrado.

Ésa es la lista que quiero usar. No significa que ya revisé todas mis tareas ni que nunca se va a escapar un error.

Quiero una comprobación que me ayude a decidir. Si después de leerla sigo sin saber qué cambió, todavía falta mostrar el resultado.
