# SI-03 · Claude, pero vago

Este plugin promete que Claude escriba menos código. Se llama ponytail, un agregado para la IA que programa en tu compu.

La idea es simple: antes de construir más cosas, preguntar si hacen falta. Le pedís un botón, no una fábrica de botones.

Su autor publicó una comparación: treinta y nueve tareas, cinco corridas por tarea, con Opus cinco punto cinco. Reporta cincuenta y tres por ciento menos código y veintiséis por ciento menos costo frente al agente sin el plugin.

Ojo: son números del autor. No son una prueba mía ni una promesa para tu proyecto.

Mi consejo para evaluarlo: usá el mismo pedido con y sin el plugin. Primero mirá si hace lo que pediste. Después compará las líneas y el costo.

Menos código puede ser mejor. Menos funciones de las que necesitabas, no. La comparación empieza por el resultado, no por el número más lindo.

# SI-04 · Tres comandos escondidos de Claude Code

Claude Code tiene una radio. Y otros comandos que vale la pena mirar antes de instalar más cosas.

Claude Code es la IA que programa en tu compu. Barra radio abre Claude FM, música lo-fi para concentrarte. Está documentado: no te lo cuento como un lanzamiento de hoy.

Barra powerup abre lecciones cortas e interactivas sobre sus funciones. Si recién empezás, puede servirte para conocer lo que ya tenés.

Y ultrathink se escribe dentro del pedido. Le pide un razonamiento más profundo en esa respuesta, sin cambiar el nivel de esfuerzo configurado para toda la sesión.

Mi consejo: no lo pegues en todos los mensajes por costumbre. Reservá lo difícil para cuando necesitás revisar más posibilidades.

Antes de grabar una demo, comprobá qué aparece en tu versión y cuenta. Que una función esté en el manual no significa que la tengas disponible en cualquier entorno.

# INF-1014 · Una pausa antes de instalar una herramienta

Antes de instalar otra herramienta, quiero hacer una pausa. ¿Qué problema concreto me resuelve?

Ver un video donde alguien la usa no alcanza para contestar eso. Puede estar buenísima y aun así no hacerme falta esta semana.

Quiero mirar tres cosas: para qué la necesito, qué permisos pide y cómo la voy a probar. Si no puedo explicar esas tres, prefiero anotarla y seguir con lo que ya tengo.

También quiero separar probar de cambiar todo mi sistema. Una prueba pequeña, con archivos de ejemplo, no es lo mismo que darle acceso al trabajo real.

No te cuento que hice ese cambio y ahorré horas. Es el criterio que quiero usar antes de sumar otra cosa.

Me interesa aprender herramientas, sí. Pero mi trabajo no es coleccionarlas. Quiero terminar una tarea y entender qué parte me ayudó a hacerla.
