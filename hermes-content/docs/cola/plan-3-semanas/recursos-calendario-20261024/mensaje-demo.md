# Pedido sintético · DEMO A

Inventado desde cero para practicar; no proviene de una conversación real.

> Soy Cliente DEMO A; quiero 3 cuadernos A5 y 2 lapiceras azules; entrega el 26/10/2026; pago al recibir.

La dirección no está informada. La fecha es una solicitud, no una promesa del negocio.

## Consigna copiable

Extraé solo los datos del mensaje a una tabla con estas seis columnas: cliente, producto, cantidad, fecha_solicitada, pago, direccion. Una fila por producto. Cuando un dato no esté, escribí POR CONFIRMAR. No consultes otras fuentes ni completes por intuición. Fuera de la tabla indicá si se puede confirmar la entrega y por qué.

## Clave de corrección redactada

Ver `pedido-esperado.csv`. Deben aparecer dos filas; no tres pedidos ni cinco productos diferentes. No se puede confirmar la entrega: falta dirección y la fecha solicitada requiere validación de operación. La pregunta de seguimiento es: «¿Cuál es la dirección de entrega?».
