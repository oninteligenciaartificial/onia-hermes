**Instalarlo — 5 minutos:**

```
# macOS, Linux o WSL
curl -fsSL https://claude.ai/install.sh | bash

# Windows, en PowerShell
irm https://claude.ai/install.ps1 | iex
```

Después, para confirmar que quedó bien:

```
claude --version     # tiene que imprimir un número de versión
claude doctor        # revisa la instalación entera y te dice si algo falta
```

Y para usarlo: abrís la terminal **en la carpeta de tu proyecto** y escribís `claude`.

⚠️ **En Windows conviene instalar antes [Git for Windows](https://git-scm.com/downloads/win)**
— sin eso, Claude Code usa PowerShell y varias cosas se comportan distinto.

**Si la terminal te da miedo, hay app de escritorio** para macOS, Windows y Linux. Hace lo
mismo con ventanas en vez de comandos.
