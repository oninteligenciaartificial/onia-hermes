# Story References

Hermes must keep Instagram Story references separate from carousel references.
Stories are faster, more personal, and more ambient. They are not meant to teach
everything. Their job is to create presence, proof of work, interaction, and
momentum.

Reference file:

`/root/.hermes/references/story-references.json`

## How Hermes Should Use Them

These references currently belong primarily to Sergio's personal brand. ONIA may
borrow the structure only when the user explicitly asks for an ONIA story with a
personal/founder mood.

Use story references when the user asks for:

- `Genera historia Sergio: <tema>`
- `Historia marca personal: <idea>`
- `Genera historia ONIA: <tema>`
- `Historia IG: <idea>`
- `Crea secuencia de historias: <objetivo>`
- Daily updates, work-in-progress, dashboard teasers, behind-the-scenes, polls,
  questions, founder routine, work mood, or quick proof.

Do not use these references for standard carousel layouts unless the user asks
for a Story-style carousel.

## Story Types

- Daily KPI story: use `story-ref-001`.
- Morning or routine collage: use `story-ref-002`.
- Quiet ambient visual diary: use `story-ref-003`.
- Annotated workflow breakdown: use `story-ref-004`.
- Cafe/work session mood: use `story-ref-005`.

## Story Rules

- Keep text short. One story should communicate one idea.
- Use 9:16 vertical format.
- Prefer real-feeling scenes: laptop, dashboard, WhatsApp, notes, coffee,
  workspace, city, client work.
- Add one interaction layer when useful: poll, slider, question, quiz, or CTA.
- Never copy third-party photos, logos, text, music cards, people, brands, or
  exact layouts.
- Convert the structure into original Sergio, ONIA, or client visuals depending
  on the lane.

## Story Sequence Template

1. Mood/proof story: show work context or result.
2. Problem story: name what businesses are losing or missing.
3. Breakdown story: show 3-4 parts of the system.
4. Interaction story: ask a poll or question.
5. CTA story: invite DM, audit, demo, or Telegram command.

## Example

Input:

`Genera historia Sergio: hoy estoy conectando Higgsfield con Hermes`

Output should include:

- 3 to 5 story frames.
- Which story reference each frame uses.
- Exact overlay text.
- Visual prompt.
- Suggested sticker or interaction.
- CTA.
