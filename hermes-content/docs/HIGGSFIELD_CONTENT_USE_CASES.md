# Higgsfield Content Use Cases

Esta es la biblioteca rapida de casos de uso para producir videos con Hermes,
n8n y Higgsfield.

Fuente machine-readable:

- `hermes-content/references/higgsfield-content-use-cases.json`

Referencia de flujo n8n:

- `hermes-content/references/n8n-higgsfield-generation-flow.md`

## Rubros prioritarios

- clinicas dentales;
- esteticas, dermatologia y belleza;
- restaurantes y cafes;
- inmobiliarias;
- gimnasios;
- ecommerce y tiendas locales;
- profesionales y marca personal;
- salud no dental;
- educacion y academias;
- turismo, hoteles y experiencias;
- automotriz, talleres y repuestos;
- constructoras, arquitectura e interiorismo;
- servicios locales;
- SaaS, software y B2B;
- Sergio marca personal.

## Regla

Para cada rubro, Hermes debe producir:

- hook;
- guion;
- CTA;
- escenas;
- prompt Higgsfield;
- claims seguros;
- negative prompt;
- assets/referencias necesarias;
- aprobacion pendiente.

n8n arma el paquete y registra el estado. Higgsfield genera. Instagram publica
solo tras aprobacion.
