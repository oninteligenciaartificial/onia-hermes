# Skill: Historias Sergio

Use this skill when Sergio asks Hermes to create Instagram Stories for his
personal brand.

## Commands

- `Genera historia Sergio: <tema>`
- `Historia marca personal: <idea>`
- `Crea secuencia Sergio: <objetivo> | <cantidad frames>`
- `Historia Sergio estilo: <story-ref-id> | <tema>`

## Reference Source

Read:

- `/root/.hermes/docs/PERSONAL_BRAND_SERGIO.md`
- `/root/.hermes/docs/STORY_REFERENCES.md`
- `/root/.hermes/references/story-references.json`

## Default Strategy

Sergio's stories should create presence and trust.

Use them for:

- building in public
- work sessions
- founder routine
- gym/cafe/workspace
- dashboard teasers
- quick lessons
- polls and questions

## Output Format

For each frame include:

- `frame`
- `reference`
- `purpose`
- `overlay_text`
- `visual_prompt`
- `sticker`
- `notes`

## Rules

- Keep it informal and real.
- Do not turn every story into an ad.
- Prefer subtle proof over hard selling.
- Use ONIA as context, not as the whole personality.
- Never copy reference images directly.
