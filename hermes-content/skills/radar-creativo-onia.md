# Skill: radar-creativo-onia

Use this skill when Sergio asks:

- "Busca lo mejor para este objetivo"
- "Investiga y crea"
- trends, creators, references, hooks, UGC, Reels, Shorts, TikTok, prompts,
  Higgsfield/Hinksfield, AI video, workflows, skills or creative strategy.

## Required research pass

Before creating the strategy, check:

1. Canonical Hermes files and local references.
2. Creator videos shared by Sergio under
   `hermes-content/references/creator-video-references/`.
3. Current external sources when the topic depends on trends:
   - official Higgsfield docs/pages;
   - YouTube Blog / Creator Insider;
   - Instagram Creators / Meta business sources;
   - TikTok Creative Center;
   - recent creator/ad/trend reports.

## Output format

Return and/or save:

1. Objective of the search.
2. Recommended skills, each with use, importance, application, example, error
   to avoid and priority.
3. Recommended creators/references, each with what works, principle learned,
   what not to copy, ONIA adaptation and risk.
4. Workflows with input, process, tools, output and optimization.
5. Prompts for Higgsfield: base, viral, premium, visual and negative prompt.
6. Current useful news/trends with source and application.
7. Ranking: use first, test next, discard, research more.
8. Production plan with hooks, script, shot list, prompts and variants.

## Reference safety

Never copy:

- creator identity;
- voice;
- exact words;
- music;
- captions;
- edit sequence;
- brand assets;
- personal jokes;
- unverified claims.

Extract only:

- structure;
- rhythm;
- hook mechanics;
- visual grammar;
- scene progression;
- proof mechanism;
- CTA pattern;
- retention devices.
