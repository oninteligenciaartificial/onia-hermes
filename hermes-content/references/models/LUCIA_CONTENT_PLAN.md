**La idea en una frase:** Lucia es una influencer de lifestyle/skincare que ES abiertamente
IA y, cada tanto, rompe la cuarta pared para mostrar CÓMO se hace y que detrás está ONIA.
La audiencia entra por lo aspiracional/relatable; ONIA capta a quien quiere eso para su marca.

- **Front-stage (gancho):** estética lifestyle/skincare natural, clean girl, relatable.
- **Back-stage (autoridad + embudo):** behind-the-scenes del pipeline, educación IA, y la
  oferta = **ONIA** (webs, automatización, "te creamos tu influencer AI"). Nuvia/skincare
  entra como CASO ("le hice el contenido a esta marca"), no como el eje.
- El "es IA" NO se esconde: es la marca y cumple de una la etiqueta obligatoria "creado con IA".

## Formatos + hooks (primer segundo manda)

**Front-stage (lifestyle):**
- **GRWM / rutina** (b-roll aplicándose + VO): *"Mi rutina de mañana en 4 pasos."*
- **Lifestyle** (b-roll movido): café, caminar, gym — audio de trend o VO corta.
- **Carrusel editorial** (foto + tipografía serif, estilo revista): *"Orden correcto de tu rutina de skincare."*

**Meta / behind-the-scenes (el diferenciador):**
- **"Cómo me hago siendo IA"** (behind-the-scenes): muestra la ficha 360°, el modelo rotulado,
  el antes/después. Hook: *"Soy 100% IA. Así hago este video."* / *"Nadie nota que no existo."*
- **Reveal / cuarta pared**: empieza como lifestyle normal y a los 3s revela el pipeline.

**Autoridad / educativo (deriva a ONIA):**
- **Torneo de modelos** (comparativa + votación): *"Seedance vs Kling vs Veo — ¿cuál es mejor? Probé los 3."* (tenemos la data real).
- **Tip de generación**: *"El error #1 al crear tu avatar IA (pierdes toda la consistencia)."*
- **HOOK DE CONVERSIÓN (de Aria)**: *"Comenta LUCIA y te mando la guía/los prompts."* →
  DM automation (n8n + IG API, carril infra, tras token IG S6) → lead ONIA.

**Venta:**
- **Caso Nuvia** (talking + producto): *"Le hice el contenido a esta marca de skincare — miren."*
- **Oferta ONIA** (talking): *"¿Querés una influencer AI o una web así para tu negocio? Eso hace ONIA."*
