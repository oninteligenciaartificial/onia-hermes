# Sergio Approved Media

Biblioteca local para referencias aprobadas de Sergio.

Usar para:

- marca personal Sergio;
- ONIA Sergio-led;
- pruebas internas de prompts, voz y video.

No usar para:

- publicar sin aprobacion;
- clientes sin consentimiento;
- impersonacion;
- claims o testimonios falsos.

Carpetas esperadas:

- `inbox/`: fotos y videos recibidos.
- `voice-inbox/`: audios de muestra.
- `processed/`: assets revisados y clasificados.
- `outputs/`: borradores generados.

Registrar todo en `manifest.json`.
