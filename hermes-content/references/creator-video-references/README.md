# Creator Video References

## Purpose

This folder is the intake inbox for creator videos Sergio shares as inspiration.
Hermes uses these videos to learn structure, pacing, hooks, scenes, camera
language and CTA patterns for ONIA/Higgsfield work.

References are not source material to copy. They are pattern studies.

## Workflow

1. Sergio sends one or more creator video links or files.
2. Hermes creates one JSON entry per reference using `template.json`.
3. Hermes extracts reusable patterns: hook, rhythm, scene structure, camera,
   subtitles, proof mechanism, CTA and safety limits.
4. Hermes updates `manifest.json` with the reference status.
5. When creating UGC videos, Hermes adapts the pattern into an original ONIA
   brief and prompt.

## Safety Rules

- Do not copy exact words, captions, music, edit sequence, face, identity,
  brand assets or product claims.
- Do not use a creator's likeness or voice without explicit consent.
- Do not treat a creator's claimed results as proof for ONIA or clients.
- Reject or quarantine references with ethical safety below 4/5.
- For client work, use references as rhythm and structure only.

## File Naming

Use:

```text
creator-video-ref-YYYYMMDD-001.json
creator-video-ref-YYYYMMDD-002.json
```

Keep raw downloaded media out of git unless Sergio explicitly asks to store it
locally. Prefer URL references and analysis notes.
