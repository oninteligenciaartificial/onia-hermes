# Veredicto: Marketing Studio nativo vs editor Remotion (2026-07-06)

Test real: `ms-mara-isdin-480p-12s.mp4` — avatar custom **Mara** + producto **ISDIN Fusion Water SPF 50** + setting Bathroom + formato Selfie Testimonial, 480p/12s. Costo: **42 creditos**.

## Resultado del test
- Mara **habla de verdad** (lipsync + voz IA), identidad consistente, baño creible.
- **Sostiene el ISDIN real en la mano**, etiqueta legible -> resuelve el problema de "packshot que se rompe" del editor.
- Guion auto-generado en **espanol**, on-brand, claims seguros. Movimiento natural (4-5 tomas).
- Contras: 480p (baja res), **sin overlays de marca/precio/CTA/subtitulos** (es UGC "limpio"), menos control fino.

## Comparacion

| | Marketing Studio nativo | Editor Remotion (nuestro) |
|---|---|---|
| Costo/video | **42-75 cr** | **~3 cr** (14-25x mas barato) |
| Avatar hablando (lipsync+voz) | Si, realista | No (subtitulos cargan el mensaje) |
| Producto en mano real | Si (no se rompe) | Packshot compuesto (puede romperse) |
| Marca/precio/CTA/subtitulos | No (UGC limpio) | Si, control total (logo, Bs.201, CTA) |
| Resolucion | 480p (o 720p mas caro) | 1080p |
| Escala/volumen | Caro | Barato, ideal |

## Veredicto: son COMPLEMENTARIOS (no uno u otro)
- **Editor Remotion** = ads branded de conversion (Nuvia con precio + CTA + subtitulos), volumen, barato. **Default.**
- **Marketing Studio** = UGC autentico de la cuenta de la influencer (habla + producto en mano, organico). Para **piezas hero/organicas** puntuales. Caro.
- **Hibrido (mejor)**: usar el clip de Marketing Studio como b-roll (Mara hablando+producto) y pasarlo por el editor para sumar marca/precio/CTA/subtitulos. ~42cr+ por pieza premium.

## Recomendacion de gasto
- Volumen diario -> editor (0.12cr fotos + edicion). 
- 1-2 piezas hero/mes por modelo -> Marketing Studio (42cr min, 480p) cuando el organico lo justifique.
- Evitar 720p/15s (75cr) salvo pieza final aprobada.
