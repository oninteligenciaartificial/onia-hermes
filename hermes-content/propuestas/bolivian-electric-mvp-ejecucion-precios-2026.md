# Bolivian Electric - MVP comercial digital ONIA 2026

## Enfoque recomendado

No vender "una web" ni "un chatbot" por separado. Vender un piloto comercial
digital que ordena la captacion, seguimiento y atencion del cliente.

Nombre comercial sugerido:

**Bolivian Electric Comercial OS - Piloto 30 dias**

Objetivo:

- Ordenar cotizaciones y seguimiento comercial.
- Mejorar la presencia web y convertirla en canal de captacion.
- Preparar chatbot y base de conocimiento sin depender de datos sensibles.
- Crear una web funcional de compra/cotizacion para productos seleccionados.

## Modulos de la primera etapa

### 1. CRM de cotizaciones y seguimiento

Problema que resuelve:

- Consultas repartidas entre WhatsApp, llamadas, vendedores y sucursales.
- Cotizaciones sin responsable claro.
- Seguimientos que dependen de memoria humana.

Incluye:

- Registro de cliente y contacto.
- Estados de oportunidad: nuevo, por cotizar, cotizado, seguimiento, ganado,
  perdido.
- Responsable asignado.
- Proxima accion y fecha de seguimiento.
- Historial basico.
- Dashboard para gerencia.
- Vista por sucursal o area.

Precio modular:

- **Setup CRM MVP:** Bs. 5.900
- **Soporte/operacion mensual:** desde Bs. 690/mes

### 2. Web de captacion comercial

Problema que resuelve:

- La web no debe ser solo vitrina. Debe generar solicitudes medibles.

Incluye:

- Home comercial.
- Paginas por categorias principales.
- Formularios de solicitud.
- Botones de WhatsApp por area/departamento.
- Captacion directa hacia CRM.
- SEO basico y estructura mobile-first.
- Analitica basica.

Precio modular:

- **Web comercial ONIA:** Bs. 4.900
- **Cuidado web mensual:** Bs. 390 a Bs. 690/mes

### 3. Chatbot y base de conocimiento

Problema que resuelve:

- Preguntas repetitivas.
- Respuestas inconsistentes.
- Dependencia de una sola persona para resolver dudas.

Incluye:

- Base de preguntas frecuentes.
- Respuestas comerciales aprobadas.
- Derivacion a vendedor humano.
- Captura de datos del cliente.
- Primer flujo para web chat o WhatsApp segun acceso aprobado.
- Entrenamiento inicial del equipo para usar respuestas y prompts.

Precio modular:

- **Chatbot inicial + base de conocimiento:** Bs. 4.500
- **Mantenimiento/monitoreo:** desde Bs. 450/mes

Nota: costos de Meta WhatsApp, IA, proveedor de chat o mensajeria se cotizan
como costos externos si aplican.

### 4. Web funcional de compra/cotizacion

Problema que resuelve:

- El cliente necesita ver productos, consultar disponibilidad y pedir compra o
  cotizacion sin perderse.

Incluye:

- Catalogo inicial por categorias.
- Ficha de producto simple.
- Carrito o lista de solicitud.
- Solicitud de compra/cotizacion.
- Envio al CRM.
- Flujo de confirmacion por vendedor.
- Preparacion para pagos QR o pasarela si gerencia lo aprueba.

Precio modular:

- **Catalogo funcional / compra asistida MVP:** Bs. 7.900
- **Integracion de pagos QR o pasarela:** desde Bs. 2.900 adicionales

Nota: en fase 1 se recomienda compra asistida/cotizacion, no ecommerce 100%
automatico, hasta validar stock, precios, sucursales y proceso interno.

## Paquete recomendado para presentar

### Piloto Comercial Digital - 30 dias

Incluye:

- CRM de cotizaciones y seguimiento.
- Web de captacion comercial.
- Chatbot inicial/base de conocimiento.
- Catalogo funcional de compra/cotizacion para categorias priorizadas.
- Dashboard basico para gerencia.
- 2 sesiones de capacitacion al equipo.
- Documentacion de uso.
- Soporte de salida durante el piloto.

Precio recomendado:

- **Implementacion:** Bs. 16.900
- **Mensual de soporte y mejoras:** Bs. 1.200/mes desde el segundo mes

Forma de pago sugerida:

- 50% anticipo para iniciar.
- 30% con prototipo funcional.
- 20% al entregar piloto.

Este precio es de entrada por oportunidad estrategica. Si el alcance crece a
mas sucursales, integraciones profundas, inventario avanzado o datos internos,
se cotiza una fase 2.

## Opcion mas completa

### Sistema Comercial + Operacion - 60 a 90 dias

Incluye todo el piloto mas:

- Roles y permisos avanzados.
- Flujos por sucursal/departamento.
- Reportes semanales automaticos.
- Inventario con carga/validacion inicial.
- Prototipo de auditoria de inventario con camara.
- Automatizaciones con n8n.
- Acompanamiento operativo.

Precio:

- **Implementacion:** desde Bs. 29.900
- **Acompanamiento mensual:** Bs. 2.500 a Bs. 3.900/mes

## Costos no incluidos

- Dominio, hosting externo o VPS si se requiere.
- Costos de API de IA.
- Costos de WhatsApp Business/Meta.
- Pasarela de pago o comisiones bancarias.
- Migracion masiva de datos historicos.
- Integracion directa con sistemas internos sin auditoria y autorizacion previa.
- Produccion grande de contenido, fotos o video.

## Orden de ejecucion

### Semana 1 - Diagnostico y prototipo base

- Entrevistar ventas, marketing, almacenes y gerencia.
- Definir estados del CRM.
- Definir categorias iniciales.
- Definir responsables y permisos.
- Disenar estructura de la web.
- Montar prototipo navegable.

### Semana 2 - CRM + web de captacion

- Crear CRM MVP.
- Crear formularios conectados al CRM.
- Crear dashboard basico.
- Crear primera version de la web.
- Validar flujo con 2 a 3 usuarios internos.

### Semana 3 - Chatbot + catalogo funcional

- Crear base de conocimiento.
- Crear chatbot inicial.
- Crear catalogo/cotizador.
- Conectar solicitudes al CRM.
- Ajustar mensajes, formularios y derivacion humana.

### Semana 4 - Capacitacion y piloto

- Capacitar equipo.
- Corregir fricciones.
- Documentar uso.
- Medir primeras solicitudes.
- Definir fase 2.

## Preguntas clave para la reunion

1. Que entienden por "compra online": pago directo, reserva, pedido o cotizacion?
2. Cuantos vendedores deben usar el CRM al inicio?
3. Que sucursales/departamentos entran en el piloto?
4. Que categorias de productos son prioridad?
5. Tienen lista de productos exportable a Excel?
6. Quien aprueba textos, precios y contenido web?
7. Que datos son privados solo para gerencia?
8. El chatbot debe responder por web, WhatsApp o ambos?
9. Que proceso no se puede interrumpir bajo ninguna circunstancia?
10. Quien sera el responsable interno del piloto?

## Guion corto para presentar

La idea no es venderles solo una pagina o un chatbot. La idea es empezar con un
piloto comercial de 30 dias para ordenar cotizaciones, mejorar la web, capturar
clientes y preparar una compra/cotizacion funcional.

Empezariamos sin tocar sistemas sensibles. Primero armamos una capa externa:
CRM, web, chatbot base y catalogo funcional. Cuando el equipo lo use y validemos
el flujo, recien pasamos a integraciones mas profundas.

La propuesta recomendada es el piloto de Bs. 16.900, con soporte mensual desde
Bs. 1.200. Eso nos permite entregar algo real, medible y util sin pedirles una
transformacion enorme desde el primer dia.

## Regla comercial para ONIA

No prometer reemplazo total del sistema actual en fase 1.

Prometer:

- orden comercial;
- visibilidad;
- mejor captacion;
- seguimiento;
- base para automatizar;
- piloto medible.

La fase 2 se vende cuando Bolivian vea el valor del piloto.
