Claude Code, de cero

La herramienta con la que construyo todo lo que ves en este sitio. Esta serie la explica desde cero, en orden: primero entender qué es, después instalarla, y recién después soltarle trabajo. Cada video te deja pudiendo hacer algo que antes no podías.

Antes de empezar, lo que nadie te dice

El plan gratis de Claude NO incluye Claude Code. Alcanza para el chat, no para esto. Hace falta un plan pago — lo digo acá arriba y no al final, para que no pierdas la tarde.

Y no reemplaza entender lo que estás haciendo. Si le pedís algo que no sabés explicar, te devuelve algo que no vas a saber arreglar.

Claude y Claude Code no son lo mismo

Entender · 7 minutos · al terminar sabés cuál de los dos necesitás

En una línea: Claude te dice cómo hacerlo; Claude Code lo hace, en tu computadora, tocando tus archivos. Uno es un consejero, el otro es un empleado. La mayoría de la gente paga el consejero creyendo que contrató al empleado.

02

Instalarlo, y tu primera skill

Usarlo · 10 minutos · al terminar lo tenés andando

requiere plan pago macOS · Windows · Linux

Los comandos del video, para copiar

# macOS, Linux o WSL
curl -fsSL https://claude.ai/install.sh | bash

# Windows, en PowerShell
irm https://claude.ai/install.ps1 | iex
claude --version   # imprime el número de versión
claude doctor      # revisa la instalación entera

# abrí la terminal EN LA CARPETA de tu proyecto y:
claude
En Windows instalá antes Git for Windows. Sin eso varias cosas se comportan distinto. Y si la terminal te da miedo, hay app de escritorio: hace lo mismo con ventanas.
