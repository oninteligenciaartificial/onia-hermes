Bóveda · MCP · nuevo

MCP sin darle permiso para todo.

MCP no es un modelo. Es una forma estándar para que un cliente como Claude Code use herramientas de un servicio externo con una interfaz clara.

Qué no hace

MCP no mejora tus permisos. Si conectás una herramienta con capacidad de borrar, cobrar o enviar mensajes, el modelo podrá pedir esa acción. El protocolo conecta; las reglas y permisos siguen siendo tu responsabilidad.

01

El modelo mental correcto

Cliente → servidor MCP → herramienta

Claude Code es el cliente. El servidor MCP publica una lista de herramientas. Cada herramienta declara qué recibe y qué devuelve. Notion, una base de datos o un CRM quedan del otro lado. Así no necesitás inventar una integración distinta para cada modelo.

Claude Code
  ↓ solicita una herramienta
Servidor MCP
  ↓ ejecuta dentro de los permisos definidos
Notion / CRM / base de datos
02

Escribí el contrato antes de conectar

Una herramienta pequeña es más segura y más fácil de revisar

Herramienta de ejemplo: get_lead_by_id

ParteEjemplo
Entradalead_id
Salidaname, status, source
PermisoSólo lectura
Fallo“lead no encontrado”, no inventar un dato
DueñoQuién revisa si devuelve algo raro

Eso es mejor que una herramienta llamada “gestionar leads” con acceso a todo. El nombre dice qué hace, el input limita qué puede pedir y la salida limita qué información vuelve al modelo.

03

Conectá y verificá antes de usar

La configuración depende del servidor; el criterio no cambia

Con un servidor HTTP compatible, el patrón en Claude Code es agregar el nombre y la URL del servidor, luego listar qué quedó conectado. Revisá siempre el comando exacto del proveedor antes de copiarlo: las URLs, el transporte y la autenticación cambian.

# agregá el servidor a Claude Code
claude mcp add --transport http <nombre> <url>

# después de configurar tu servidor MCP
claude mcp list

# dentro de Claude Code
/mcp
# revisá estado, autenticación y permisos
Orden seguro: primero lectura, después validación y recién después una aprobación humana para escribir, borrar, cobrar o enviar. Si no podés explicar quién aprueba, esa herramienta no está lista para un agente.
