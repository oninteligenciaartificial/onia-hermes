# Letra de los anuncios de Onia Platform

`archivo-latin.woff2` y `archivo-latin-ext.woff2`: **Archivo** variable (peso 100–900, ancho 62–125), la misma
letra del sitio onia.com.bo y del logo (`web-factory/apps/onia-platform/src/app/layout.tsx`).

- Fuente: Google Fonts (`fonts.gstatic.com/s/archivo/v25/`), bajada el 2-oct-2026.
- Licencia: SIL Open Font License 1.1 (se puede usar, embeber y redistribuir).
- La usa `../anuncio-render.js` por `@font-face`, así el render no depende de las fuentes instaladas en la máquina.
